# ViAI - Vim Advanced Integrated

ViAI (pronounced "vee-eye") is a fork of [Vim](https://github.com/vim/vim),
developed by Hirohito Higashi (h-east), a former Vim maintainer, making full
use of AI assistance.

## What is ViAI?

ViAI started from Vim 9.2.1186, so it has all the features of Vim:
multi-level undo, syntax highlighting, command line history, on-line help,
spell checking, Vim9 script, a GUI, and much more.

The name stands for "Vim Advanced Integrated".  It happens to be the same
words as the "AI synthesis" (Advanced Integrated) of the KORG M1 synthesizer,
released in 1988, the year in which Bram Moolenaar started writing Vim.

## Development policy

* ViAI aims to be an editor in which these Vim9 script plugins work well:
  * [lsp.vim](https://github.com/h-east/lsp.vim): an LSP client
  * [vim9ls](https://github.com/h-east/vim9ls): a language server for Vim9
    script

  They will be bundled with ViAI and enabled by default, so that they work
  as soon as a file of the "vim" filetype is opened.  They can be disabled
  in your configuration.
* ViAI adds features of its own, while keeping compatibility with Vim as far
  as possible.
* The patches of Vim are imported into ViAI as a rule.

## Use of AI tools

* AI tools may propose a specification, but humans work it out and decide
  on it.
* Code generated by AI tools is always reviewed by a human, for both its
  specification and its implementation, before it is committed.

The maintainer is responsible for all changes in ViAI, however they were
written.

## How bugs are handled

* A bug that occurs only in ViAI: please open an issue in this repository to
  report it.  The maintainer fixes it in ViAI with a pull request.
* A bug that also occurs in Vim: please open an issue in this repository to
  report it.  The maintainer fixes it in ViAI and reports it to Vim.  When
  Vim fixes it later, ViAI takes the fix of Vim.
* A bug that occurs only in Vim: please open an issue in the Vim repository
  to report it.

## Differences from Vim

* The programs are named `viai`, `gviai`, `viaidiff`, etc., and the runtime
  files are installed in their own directory, so that ViAI can be installed
  next to Vim.  `ex`, `view`, `xxd` and `vimtutor` are not installed.
* ViAI has its own version number, starting at 1.0.  `v:version` and
  `has('patch-...')` still report the Vim version.  Use `has('viai')` to check
  for ViAI.
* ViAI uses your Vim configuration, unless its own configuration exists:
  `~/.viairc`, `~/.viai/` or `$XDG_CONFIG_HOME/viai/` (`$HOME/_viairc` or
  `$HOME/viaifiles/` on MS-Windows).
* The viminfo file is `~/.viaiinfo`.  The first time, the history and marks
  of `~/.viminfo` are taken over.

See `:help viai` ([`runtime/doc/viai.txt`](./runtime/doc/viai.txt)) for all
the differences.

## Building and installing

ViAI is built like Vim.  All the stuff for compiling is in the
[`src`](./src/) directory, see [`src/INSTALL`](./src/INSTALL) for Unix and
[`src/INSTALLpc.txt`](./src/INSTALLpc.txt) for MS-Windows.  On Unix:

```
./configure
make
make install
```
