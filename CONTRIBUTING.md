# Contributing to ViAI

Bug reports and feature requests are welcome.  Please open an issue in this
repository.

## Pull requests

Pull requests from others are generally not accepted.  If you would like to
change something, please open an issue first.  A pull request may be accepted
when it has been agreed on in the issue.

## Reporting issues

Try reproducing the problem without any of your plugins or settings:

    viai --clean

Describe exactly how to reproduce the problem.  For example, instead of
"insert some text" write what you typed: `ahere is some text<Esc>`.

## Runtime files

Problems with runtime files, such as syntax and indent files, can be reported
here as well.  Many of these files come from Vim and have a maintainer, see
the header of the file.  When ViAI has not changed the file, you may be asked
to report the problem to its maintainer or to Vim.
